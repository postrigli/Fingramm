# Fingramm

Android-приложение, которое помогает семье систематизировать финансы. Пользователь отвечает на простые вопросы
(онбординг), приложение собирает «финансовую картину» — ключевые показатели с диаграммами, — после чего учёт ведётся
вручную, а для каждого показателя есть подсказка: что это, как считается, какая норма и как улучшить.

Всё работает **локально и офлайн**: нет бэкенда, регистрации, сторонней аналитики и разрешения `INTERNET`.

> **Статус.** CI (GitHub Actions) на PR #1 зелёный: `ktlintCheck`, `detekt`, unit-тесты `:domain` и `:app` (репозитории
> на Room in-memory через Robolectric), `lintRelease`, `assembleRelease`/`assembleDebug` и инструментальные тесты на
> эмуляторе (UI онбординга, миграции Room). Ручная проверка на устройстве, в том числе виджетов, — см.
> [«Что осталось проверить»](#что-осталось-проверить) и раздел 13 в [DECISIONS.md](DECISIONS.md).

## Возможности

- **Онбординг:** 10 вопросов по одному на экран, прогресс-бар, возврат назад, пропуск необязательного, пояснение
  «зачем мы это спрашиваем», валидация и разделители тысяч. Ответы можно редактировать в любой момент.
- **Сводка:** свободный денежный поток, норма сбережений, долговая нагрузка, подушка в месяцах, доля обязательных
  расходов, чистый капитал. Режимы **План / Факт**, статус = цвет + значок + слово, подсказка «?» у каждой карточки.
  Диаграммы: структура расходов (кольцо), доходы и расходы по месяцам (столбцы), прогресс целей.
- **Операции:** быстрая форма (сумма → категория → «Сохранить»), группировка по дням, фильтры и поиск, свайп-удаление
  с отменой, обзор месяца с планом из опроса, лимиты по категориям, регулярные операции с подтверждением.
- **Регулярные операции:** повтор ежемесячно (день выбирается в календаре) или еженедельно (дни ПН–ВС, как у будильника)
  плюс время уведомления; в нужный день приходит напоминание, операцию можно подтвердить одним нажатием.
- **Цели:** прогресс, ручное пополнение, прогноз срока и сумма «сколько откладывать в месяц».
- **Напоминания:** вечерние или еженедельные, мягкие, не приходят, если операции уже вносились; переживают перезагрузку.
- **Виджеты рабочего стола** (долгое нажатие на рабочем столе → «Виджеты» → Fingramm):
  - **2×2 «Добавить операцию»:** кнопки «Расход» и «Доход» открывают форму с выбранным типом.
  - **4×2 «Показатели месяца»:** доходы, расходы и остаток текущего расчётного месяца плюс те же две кнопки;
    нажатие на показатели открывает сводку. Растягивается до 5×3. Если в приложении включена блокировка, суммы на
    виджете скрыты (••••). Обновляется при изменении данных, раз в час и при смене даты.
- **Расчётный месяц:** по умолчанию календарный (с 1 числа), в «Ещё → Настройки → Расчётный месяц» можно выбрать день
  начала 1–28, если доход приходит в середине месяца. Влияет на сводку, обзор и фильтры операций, лимиты, цели, график
  по месяцам и виджет; операции не меняются. При первом запуске об этом не спрашиваем.
- **Данные:** экспорт/импорт JSON (замена или слияние), выгрузка операций в CSV, удаление всех данных.
- **Безопасность:** необязательная блокировка биометрией/PIN устройства; `allowBackup=false`.
- Светлая и тёмная темы, Dynamic Color (Android 12+), русский интерфейс (все строки — в `strings.xml`).

## Стек

Kotlin · Jetpack Compose (Material 3) · MVVM + Clean-lite · Room · Hilt · Coroutines/Flow · DataStore ·
Navigation Compose · WorkManager · kotlinx.serialization. Графики нарисованы на Compose Canvas — обоснование и
таблица версий в [DECISIONS.md](DECISIONS.md#1-библиотека-графиков-и-версии-зависимостей-подтверждение-перед-этапом-1).

## Структура

```
domain/   чистый Kotlin/JVM: модели, расчёт показателей, валидация опроса, прогноз целей,
          расписание регулярных операций, бэкап (кодек, проверка, слияние), CSV
app/      Android: Room (data/db), репозитории (data/repo), уведомления, блокировка,
          Compose-экраны (ui/…), навигация, виджеты (widget), Hilt (di)
config/   конфигурация detekt;  .editorconfig — ktlint
tools/    icon: генератор векторной иконки (params.json → XML и SVG)
```

Пороги «нормы» лежат в одном файле — `domain/src/main/kotlin/app/fingramm/domain/metrics/Benchmarks.kt`.

## Скачать APK без сборки на своём компьютере

GitHub Actions собирает готовый **debug-APK** при каждом запуске CI (`.github/workflows/ci.yml`, job `android`).

1. Откройте вкладку **Actions** репозитория и выберите последний успешный (зелёный) запуск workflow **CI**.
   Для pull request — тот, что относится к его последнему коммиту.
2. Внизу страницы запуска, в разделе **Artifacts**, скачайте **`app-debug`** (нужен вход в GitHub; артефакты
   хранятся 90 дней). Это zip с файлом `app-debug.apk`.
3. Распакуйте архив, перенесите APK на телефон и установите его. Android попросит разрешить установку из
   неизвестных источников для приложения, через которое вы открываете файл. Нужен Android 8.0 (API 26) или новее.

Debug-APK подписан отладочным ключом, поэтому устанавливается на любое устройство, но не годится для публикации.
Артефакт `app-release-unsigned` — неподписанная release-сборка: на устройство она не устанавливается, пока её не
подписать своим ключом (см. ниже). После слияния PR в `main` workflow можно запускать вручную (**Actions → CI → Run workflow**); локально APK
собирается командой `./gradlew assembleDebug`, файл появится в `app/build/outputs/apk/debug/`.

## Сборка

Нужны JDK 17 и Android SDK (платформа 36). Проще всего открыть проект в Android Studio.

```bash
./gradlew assembleDebug          # отладочная сборка
./gradlew installDebug           # установка на подключённое устройство/эмулятор
./gradlew assembleRelease        # release (без подписи, если нет keystore.properties)
```

Подпись release: положите рядом с `build.gradle.kts` файл `keystore.properties` (в `.gitignore`):

```properties
storeFile=release.jks
storePassword=…
keyAlias=…
keyPassword=…
```

### Что осталось проверить

Сборка, unit-тесты и инструментальные тесты на эмуляторе (9 UI-тестов онбординга и 2 теста `MigrationTest`, job
`instrumented`, API 34) проходят в CI. Схема Room версии 1 закоммичена в `app/schemas/`; при изменении схемы БД
увеличьте версию, добавьте миграцию и закоммитьте новый файл оттуда. Локально: `./gradlew connectedDebugAndroidTest`.

Остаётся ручной прогон на устройстве: онбординг → сводка → добавление операций → экспорт, очистка, импорт; напоминания
(разрешение на уведомления, перезагрузка), блокировка приложения, тёмная тема, TalkBack, виджеты (добавление на рабочий
стол, растяжение 4×2 → 5×3, суммы при включённой блокировке, нажатия при уже открытом приложении, смена месяца).

## Проверки качества

```bash
./gradlew ktlintCheck detekt     # стиль и статический анализ (ktlintFormat — автоисправление)
./gradlew test                   # unit-тесты
./gradlew lintRelease            # Android Lint
```

То же выполняет CI (`.github/workflows/ci.yml`): быстрый job для `:domain` без Android SDK, полный job для `:app`
и ручной job с эмулятором для инструментальных тестов.

Тесты:

| Что | Где | Как запускается |
|---|---|---|
| Показатели, граничные случаи (ноль дохода, долги > дохода, пороги), деньги, валидация, прогноз, расписание, бэкап | `domain/src/test` | JVM |
| Репозитории: фильтры, поиск, регулярные операции, экспорт → очистка → импорт | `app/src/test` | Robolectric |
| Время напоминаний, маршруты навигации, дни недели в маске БД, отметка системного окна | `app/src/test` | JVM |
| Блокировка приложения: включение, фон, выбор файла | `app/src/test` | Robolectric |
| Виджеты: разбор действий, раскладки инфлейтятся, суммы месяца, скрытие при блокировке | `app/src/test` | Robolectric |
| Расчётный месяц: SQL-агрегат для всех дней начала, смена настройки, бэкап, виджет; подписи периода | `app/src/test` | Robolectric / JVM |
| UI онбординга, миграции Room | `app/src/androidTest` | эмулятор/устройство |

## Формат резервной копии

```jsonc
{
  "app": "fingramm",
  "schemaVersion": 1,
  "exportedAt": "2026-10-10T10:00:00Z",
  "data": {
    "profile": {…}, "survey": {…}, "incomeSources": […], "assets": […], "debts": […],
    "categories": […], "transactions": […], "recurringTemplates": […], "goals": […],
    "categoryLimits": […], "reminder": {…}, "monthStartDay": 1
  }
}
```

Суммы — целые числа в копейках/центах, даты — `yyyy-MM-dd`. `monthStartDay` (1–28) необязателен: в старых файлах его
нет, и месяц календарный. Файл не шифруется. При несовместимых изменениях формата
увеличивайте `BACKUP_SCHEMA_VERSION` в `domain/…/backup/BackupData.kt`.

## Миграции базы данных

`AppDatabase.VERSION` сейчас 2 (миграция `MIGRATION_1_2`: расписание и время уведомления регулярных операций). Для новой версии: увеличьте `VERSION`, добавьте `Migration` в `AppDatabase.MIGRATIONS`,
закоммитьте новый файл схемы из `app/schemas/` — `MigrationTest` проверит путь с каждой старой версии.

## Что вне v1

Облачная синхронизация и несколько устройств, участники семьи и роли (поле `memberId` зарезервировано), QR чеков,
импорт банковских выписок, мультивалютность, уроки и персональные рекомендации, виджеты, iOS.

## Дисклеймер

Показатели и ориентиры — общепринятые, а не персональная финансовая, инвестиционная или налоговая рекомендация.
